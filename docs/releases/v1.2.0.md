# 荒野象棋 v1.2.0

首次公开发布：饥荒风格的本地象棋桌面应用，支持普通象棋与跨颜色混洗揭棋。

## 下载与启动

下载本页附件 **`wilderness-xiangqi-1.2.0-windows-x64.zip`**，完整解压到可写文件夹，运行 **`荒野象棋.exe`**。主菜单中先选玩法，再选对手、执子方和难度，点击“开始对局”。

适用于 **Windows 10 / 11 x64**，建议 8 GB 以上内存；不要求 GPU、Node.js 或 Python。发行包已经包含本地引擎与匹配权重，下载完成后可以断网下棋。

GitHub 自动附带的 `Source code` 是源码，不能替代上述即用压缩包。`Pikafish-source-2026-09-06.zip` 为随包引擎的对应源码，不是另一个游戏安装包。

## 本版内容

- 两种玩法，各含人机对弈、AI 观战、同机双人，共六种组合。
- 普通棋使用官方 Pikafish 2026-09-06；混揭使用不读取底牌的概率 AI。
- 主菜单、难度选择、暂停、单步、悔棋、棋盘翻转与公开棋谱导出。
- 角色徽章棋子、象棋主题图标、柔和落子声与可记忆音量。
- 普通棋红胜 / 和棋 / 黑胜分析、参考走法和走势；混揭优势指数。

## SHA-256 校验

发行附件提供校验文件。在解压前，可用 PowerShell 计算下载包的 SHA-256，并与附件中的对应条目比较：

```powershell
Get-FileHash .\wilderness-xiangqi-1.2.0-windows-x64.zip -Algorithm SHA256
```

启动器没有商业代码签名，Windows 可能提示未知发布者。请确认文件来自本仓库发行页、校验相符，再决定是否运行；不需要关闭系统防护。

## 使用边界与许可

混揭规则为“将帅固定、其他 30 子红黑混洗、走后揭示”，不同于常见各自洗子的揭棋。其 AI 尚无正式棋力评级，优势指数不是胜率。普通引擎的概率也是局面估计，不是必胜承诺。

本版未实现完整比赛长将 / 长捉裁判、联机、存档恢复或棋谱导入。关闭程序会丢失当前棋局，请先导出需要保留的公开棋谱。
